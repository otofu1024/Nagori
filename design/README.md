# デザイン素材

ブランドと画面の参考画像、生成素材の元画像、採用した生成プロンプトを置いています。

| ファイル | 内容 |
|---|---|
| `brand-reference.png` | アプリアイコンとワードマークの参考画像 |
| `ui-reference.png` | アプリ画面の参考画像 |
| `brand-prompts.json` | 採用したブランド素材の生成プロンプト |
| `brand-assets/*-source.png` | アイコンとワードマークの生成元画像 |

アプリで使う縮小済み画像は[`src/lib/assets`](../src/lib/assets/)、アプリアイコンは[`src-tauri/icons`](../src-tauri/icons/)にあります。参考画像全体を背景に使わず、色、余白、角丸、アイコンを画面作りの参考にします。
