## 数式描画回数の計測（2026-10-02）

renderMathが変換へ進んだ回数と、全mountの撤去で結果を破棄した回数を記録できるようにした。記録先はsrc/lib/mathStats.tsのカウンタで、globalThis.__NAGORI_MATH_STATS__がtrueの時だけ数える。通常利用ではフラグが未設定のため何も記録せず、描画処理も変えていない。常駐サーバーと新規依存は加えていない。

Nodeテストで次の経路を再現した。同じ本文のContextに複数のmountがあっても描画開始は1回だった。一部のmountを撤去しても結果は破棄されなかった。全mountを撤去すると破棄が1回記録され、本文を変えずに同じ式を再表示すると描画開始が2回目になった。フラグ未設定では描画しても両方0回だった。コード上の再処理経路は、このテストで確認できた。

実アプリのWebKitで繰り返しが起きているかは未確認。今回の確認はNodeテストだけで、GUIでの測定は行っていない。メモリの増加を再処理で説明できるかも分かっていない。次は計測フラグを有効にしたビルドで、記事の切替や再表示の前後に回数を読み、WebKitの保持と分けて確認する。
