# リリース前チェックリスト

## 自動確認

リポジトリのルートで実行します。

```sh
npm run check
npm test
(cd src-tauri && cargo test)
npm run build
```

`npm test`は`tests/*.test.ts`が対象です。WKWebViewの確認には[専用手順](../tests/wkwebview/README.md)を使います。記載の手順でサーバーを起動し、Swiftの確認アプリを実行してください。

## Macアプリでの確認

| # | 手順 | 期待する結果 |
|---:|---|---|
| 1 | 日本語を入力し、変換候補を選んで確定する。 | 確定した文字とカーソル位置が保たれ、自動保存される。 |
| 2 | 日本語の変換中に取り消し、削除、別の段落への移動を試す。 | 未確定文字が本文へ重複せず、変換後に編集を続けられる。 |
| 3 | 記事を編集して自動保存を待ち、Cmd＋Zで戻してからCmd＋Shift＋Zでやり直す。 | 保存後もUndoとRedoが動き、本文が保存時の内容と一致する。 |
| 4 | 未編集の記事を外部エディタで変更し、Nagoriへ戻る。 | 外部の変更を読み込み、記事を最新の内容で表示する。 |
| 5 | 未保存の編集がある記事を外部で変更する。 | 競合を知らせ、編集中の本文を保持して自動保存を止める。 |
| 6 | 読み取り専用の場所で記事を編集して保存する。 | 保存失敗を知らせ、本文を保持して再試行や別名保存を選べる。 |
| 7 | 保存中に別の記事やワークスペースへ切り替え、アプリを終了する。 | 保存の完了を待ち、未保存の本文を失わない。 |
| 8 | 画像をコピーして本文へ貼り付け、Finderから別の画像をドロップする。 | 画像が`assets`へコピーされ、本文に相対パスで表示される。 |
| 9 | 同じ名前の画像がある状態で挿入し、複数画像もまとめてドロップする。 | 既存画像を上書きせず、複数画像の挿入を1回のUndoで戻せる。 |
| 10 | ファイルとフォルダをゴミ箱へ移し、元に戻す。 | 元の場所へ戻り、同名の項目がある場合は別名で復元される。 |
| 11 | ゴミ箱の項目を完全削除し、ゴミ箱を空にする。 | 確認の後、対象がmacOSのゴミ箱へ移る。 |
| 12 | File Treeからファイルとフォルダを別のフォルダへドラッグする。 | ワークスペース内で移動し、ツリーと開いている記事が追従する。 |
| 13 | 同名の項目があるフォルダへドラッグする。 | 上書きせず、移動できない理由を表示する。 |
| 14 | Cmd＋Shift＋Fでワークスペース全体を検索し、結果を開く。 | 一致した記事が開き、該当箇所を選択して表示する。 |
| 15 | 全体検索で大文字小文字と正規表現を切り替える。 | 各設定に応じた結果が出て、上下キーとEnterで選べる。 |
| 16 | Cmd＋Fで検索し、1件置換と一括置換を行う。 | 置換結果が本文に反映され、一括置換を1回のUndoで戻せる。 |
| 17 | Cmd＋Oでワークスペースを開き、記事やフォルダを作成して名前を変える。 | 選んだ場所に作成され、名前変更後も一覧と開いている記事が更新される。 |
| 18 | Quick Openでファイル名とパスを検索する。 | 絞り込んだ記事を開き、空欄では最近開いた記事が表示される。 |
| 19 | Live PreviewとPreviewを切り替え、記号のない箇所も編集する。 | 本文とUndo履歴を保ち、Previewでは入力や装飾を止める。 |
| 20 | リストでTabとShift＋Tab、表でTabとEnterを使う。 | リストの階層を変え、表では次のセルや行へ移動して必要な行を追加する。 |
| 21 | 選択時のツールバー、本文の右クリックメニュー、メニューバーから装飾する。 | 太字、斜体、取り消し線、リンク、コード、段落操作が使える。 |
| 22 | 対応する言語のコードブロックとインラインコード、LaTeX数式を開く。 | コードの色分けと数式が表示され、原文を編集できる。 |
| 23 | 目次の表示を切り替え、項目をクリックまたはキーボードで選ぶ。 | 目次の表示が保存され、選んだ見出しへ移動する。 |
| 24 | サイドバーの全ノート、スター付き、最近見たノート、ゴミ箱を切り替える。 | 各一覧が正しい順で表示され、スターの付け外しが反映される。 |
| 25 | 設定でテーマ、本文幅、字体、自動保存、ゴミ箱の期限を変えて再起動する。 | 設定した値が再起動後も使われる。 |
| 26 | 設定の「すべて初期値に戻す」を実行する。 | 表示設定は初期値に戻り、ワークスペース、スター、閲覧記録は残る。 |
| 27 | メニューとキー操作でフォルダ、検索、保存、設定、Previewを開く。 | メニューの表示と各キーが対応する操作を実行する。 |
| 28 | 集中モードとタイプライター表示を切り替え、再起動する。 | 表示とスクロールが切り替わり、選んだ状態が再起動後も残る。 |
| 29 | サイドバーと目次の幅をドラッグし、ウィンドウを狭めて広げる。 | 読める本文幅を保ち、保存した幅へ戻る。 |
| 30 | ライト、ダーク、macOSに合わせるを切り替え、画像とテキストも開く。 | テーマが反映され、対応形式は表示され、未対応ファイルは理由を示す。 |
