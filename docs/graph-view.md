# グラフビュー

左の欄で、ゴミ箱の下にある「グラフビュー」を押すと、本文の場所にグラフが表示されます。もう一度押すと本文へ戻ります。

開いているワークスペースの`.md`ファイルを点として表示します。点の名前はFront Matterの`title`を使い、なければ拡張子を除いたファイル名を使います。`tags`に文字列か文字列の一覧があれば、タグの点も表示します。

Markdownの相対パスのリンクと`[[ファイル名]]`のwikiリンクを線で結びます。wikiリンクは同じフォルダ、ワークスペースのルートからのパス、ワークスペース内で一意のファイル名の順で解決します。同名の候補が複数あるときは線を作りません。外部のURL、ワークスペース外へのリンク、ブログの`/posts/<slug>`は対象外です。wikiリンクの抽出はグラフ用で、本文の編集やリンクを開く操作は既存のエディタの仕様に従います。

点を押すと、その文書を開きます。今の文書の点はアクセント色で表示します。点や背景はドラッグでき、背景を離すと慣性で動きます。スクロールやピンチで拡大縮小し、点にカーソルを重ねると関係する点と線が強調されます。名前は拡大に合わせて表示されます。キーボードでは矢印キーで点を選び、Enterで文書を開き、`+`と`-`で拡大縮小できます。

グラフを開いても編集中の本文とUndo履歴は保持され、自動保存は続きます。文書やタグ、リンクはファイルの変更に合わせて更新されます。

本文はRust側で読み、名前、タグ、リンクだけを画面へ渡します。名前は決まった大きさの字体で描きます。描画が落ち着くとフレームの更新を止め、グラフを閉じるとCanvasとシミュレーションを解放します。
