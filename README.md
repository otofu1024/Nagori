# Nagori

macOS向けの軽量なMarkdownエディタ。ローカルのプロジェクトフォルダを開き、Live Previewで編集、Previewで閲覧できます。

現在は開発・検証中で、本番リリースはまだありません。

## 開発版

実装・仕様書・ビルド手順・検証記録は[developブランチ](https://github.com/otofu1024/Nagori/tree/develop)にあります。

- `main`：本番リリース用。初回リリースまではこのREADMEのみ。
- `develop`：本番前の統合・試用・実験用。
- `feature/<機能名>`：`develop`から分岐する機能追加・修正用。

検証後、`develop`の実装を`main`へ統合して本番リリースします。
