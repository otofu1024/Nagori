# Nagori

ローカルのブログ記事を書くための、macOS向けMarkdownエディタ。Tauri 2 / Svelte 5 / TypeScript / CodeMirror 6 / Rustで実装しています。

## 起動

Node.js 24、Rust 1.90以上、Xcode Command Line Toolsが必要です。

```sh
cd ~/Nagori
npm ci
npm run tauri dev
```

ローカル試用用のアプリは次のコマンドで生成します。

```sh
npm run tauri build
open src-tauri/target/release/bundle/macos/Nagori.app
```

ビルド対象はこのMacのApple Silicon（arm64）。バンドルの最低OS設定はmacOS 13、フロントエンドのビルド対象はSafari 16です。開発・確認環境はmacOS 26.6.2 / arm64であり、過去のmacOSやIntelで動作確認済みという意味ではありません。ローカル試用版にはad-hoc署名を付けます。ローカル試用用DMGも生成できます。Developer ID署名・公証・自動更新は外部配布時に追加します。

ユーザー提供の[デザイン参考](design/README.md)に合わせてUIを調整しました。File TreeとEditorを中心に、白・濃紺・ミント／シアンの色、余白、アイコン、浮動ツールバーを取り入れています。上部バーからファイル検索、Light / Darkの直接切替、サイドバー表示切替を操作できます。テーマは既定でmacOSの外観に従います。設定画面でライト・ダークに固定することもできます。本文の初期サイズは19px、ファイル名などの主要UI文字は13〜14pxです。

macOSのタイトルバーをコンテンツに重ね、ウィンドウ操作ボタンとロゴを同じ上部バーに収めます。上部バーの空いた領域からウィンドウを移動できます。

本文の下には状態バーを置きません。Markdownの記事とテキストファイルでは、本文ヘッダーのLive Previewボタンの左に文字数を表示します。

## 設定画面

アプリメニューの「設定…」（Cmd+,）か、サイドバー下部の「設定」で開けます。表示・エディタ・サイドバー・ゴミ箱の4つに分かれ、変えた内容はすぐ反映され、保存もされます。Escで閉じると、開く前の場所へフォーカスが戻ります。「すべて初期値に戻す」は確認の後、表示やエディタの項目を初期値へ戻します。最近編集の記録、スター、ワークスペースは消しません。

- 表示: テーマ（ライト・ダーク・macOSに合わせる）、本文の文字サイズ（12〜32px）、本文の幅（560〜1000px）、行間（1.4〜2.4）、字体（ゴシック・明朝）。本文の幅・行間・字体は、Live PreviewとPreviewの両方に効きます。
- エディタ: 自動保存までの時間（0.3〜5秒）、記事を開いた時の表示（Live Preview・Preview）、集中モード、タイプライター表示、見出し1〜3の下線。
- サイドバー: 最近編集の件数（10〜50件）と目次の表示。
- ゴミ箱: 保存期限（7日・14日・30日・60日・90日・無期限）。期限を過ぎたものは、ワークスペースを開いた時にmacOSのゴミ箱へ送ります。

## ターミナルから開く（macOS）

Nagori.appを`/Applications`または`~/Applications`へ置き、アプリを開いてください。アプリメニュー（Nagori）の「nagoriコマンドを登録…」を実行します。起動スクリプトはアプリに同梱しており、開発フォルダやNode.jsは不要です。

登録先は`/usr/local/bin/nagori`です。書き込み権限がない場合はmacOSの管理者認証を使います。同名の別コマンドは上書きしません。登録の解除は、同じメニューの「nagoriコマンドの登録を解除」で実行できます。アプリを移動・改名する場合は、移動前に登録を解除し、移動後に登録し直してください。

以前の開発用コマンドが`~/.local/bin/nagori`に残っている場合、そちらが先に使われることがあります。`command -v nagori`とリンク先を確認してください。Nagoriは既存の登録を勝手に削除しません。`/usr/local/bin`がPATHにない環境では、シェル側で追加してください。

```sh
nagori .                # 現在のフォルダをWorkspaceとして開く
nagori test.md          # 現在のフォルダを開き、test.mdを選択する
nagori "drafts/記事.md"  # 現在のフォルダ内の相対パスも指定できる
nagori --help
```

引数なしは`nagori .`と同じです。現在のフォルダ外のファイルを指定した場合は、そのファイルの親フォルダをWorkspaceにします。引数は1件までで、存在しない対象は作成しません。アプリ同梱のコマンドは、登録元のNagori.appを開きます。リポジトリ内の開発用スクリプトはReleaseアプリを優先し、なければ`~/Applications/Nagori.app`、`/Applications/Nagori.app`を探します。

macOS標準の`open`で起動中のNagoriにも要求を渡します。初回起動では指定先を前回Workspaceの復元より優先します。起動後の切り替えではIME終了と現在の記事の保存を待ち、保存失敗・競合時は現在の記事を保持します。コマンドの終了コードはmacOSへの起動要求の結果であり、アプリ内の保存・記事読み込み完了を示しません。

CLI対応前のNagoriが起動中の場合は、一度終了してから使ってください。

## 使い方

フォルダを開き、左のファイル一覧から記事を選択します。記事とフォルダの作成は一覧上部の＋・フォルダボタン、名前変更とゴミ箱への移動は右クリック（キーボードではShift＋F10）から。Inline RenameはEnterで確定、Escapeでキャンセルします。ファイル移動はFinderで行います。名前変更時のMarkdown参照の自動更新は行いません。

本文はLive Previewで表示し、カーソルや選択を含む要素のMarkdown記号を表示します。右上のボタンかCmd＋Shift＋Lで閲覧専用のPreviewに切り替えられます。Previewでは選択しても記法を表示せず、本文入力・装飾・タスクのチェック・画像挿入を無効にします。検索・選択・コピーは使えます。Live Previewへ戻ると編集を再開でき、本文・Undo履歴を維持します。Live Previewでは選択時のツールバーで装飾し、本文の右クリックメニューから画像を挿入できます。画像は記事の隣の`assets`へコピーされ、元画像と同名画像を上書きしません。

サイドバーの「最近見たページ」欄は外しました。記事を開くと、その時刻を記録します。記録した時刻は「最近編集」の並びに使い、開いただけの記事も一覧に入ります。同名のファイルは、小さく表示した親フォルダで区別します。

サイドバーのナビから、「すべてのノート」（記事を名前順に表示）、「スター付き」（スターを付けた記事）、「最近編集」（更新日時と開いた時刻の新しい方の順に、設定の件数まで）、「ゴミ箱」を開けます。記事のスターは本文ヘッダーのスターボタンか右クリックメニューで付け外しします。ナビの項目をもう一度押すか「フォルダ」を押すと、File Treeに戻ります。

記事やフォルダを右クリックの「ゴミ箱に移動」で移した項目は、アプリ内の「ゴミ箱」から元に戻せます。「完全に削除」と「ゴミ箱を空にする」は、項目をmacOSのゴミ箱へ移します。

見出し1〜3には、本文の幅いっぱいの細い灰色の線を表示します。ATXとSetextのどちらにも付き、Live PreviewとPreviewで共通です。サイドバー下部には「別のフォルダを開く」と「設定」を残し、画像付きカードは外しました。

文字を選ばずにCmd＋Bを押すと、太字の記号`****`の間から入力できます。Cmd＋Iは斜体の記号`**`の間から入力します。閉じる記号の直前でもう一度押すと、記号の外へ出て普通の文字を入力できます。途中で押すと前半を閉じ、後半を開き直します。開く記号の直後では前へ出ます。空の記号の間でもう一度押すと、記号を消します。何も入力せずにカーソルを外へ移すか本文からフォーカスを外すと、操作で作った空の記号だけを自動で消します。自動削除はUndoの履歴に追加しません。メニューバーの太字・斜体も同じ操作です。

本文を右クリックするかShift＋F10を押すと、標準の切り取り・コピー・貼り付け・全選択に加えて、見出し・リスト・引用への変更、表・区切り線・画像の挿入を使えます。段落操作は1回のCmd＋Zで戻せます。読み取り専用、Preview、日本語の変換中、ファイル処理中は編集項目を使えません。コード・Front Matter・数式内では段落操作を無効にします。Markdown以外では標準編集の4項目だけを表示します。

JSONやコードなど、Markdownと画像以外のファイルも、UTF-8のテキストであれば等幅のプレーンテキストとして開いて編集できます。自動保存や競合の扱いはMarkdownと同じで、Live Previewや装飾、シンタックスハイライトは使いません。テキストではないファイルは、理由を表示して開きません。

本文に十分な幅がある時は、見出し1〜4の目次を右に表示します。初期幅220pxでは中央の領域が1068px以上ある時にその幅で表示し、狭い時は最小180pxまで縮めます。目次の文字はファイル名と同じ14.5pxです。目次をクリック、またはTabで選んでEnterを押すと、その見出しへ移動して本文にフォーカスを戻します。アクセント色が付いた項目が今読んでいる節です。Previewでも使えます。対象は見出しのあるMarkdownの記事です。

Markdownの記事では、本文ヘッダーのLive Previewボタンの横にある目次ボタンで表示を選べます。表示メニューの「目次を表示 / 非表示」も同じ操作です。隠すと境界線も消え、本文の列が広がります。初期値は表示で、選んだ状態は再起動後も有効です。最小幅180pxも残せない時は自動で隠れ、ボタンの案内で理由を伝えます。目次ボタンがオンなのに幅が足りずに隠れている時は、本文の上に「画面の幅が足りないため、目次を表示できません」と案内を出します。

サイドバーと本文、本文と目次の境界線をドラッグすると幅を変えられます。サイドバーは200〜420px、目次は180〜360pxです。境界線へTabでフォーカスを当て、左右の矢印キーでも動かせます。ダブルクリックでサイドバー272px、目次220pxの初期値へ戻せます。幅は設定に保存し、再起動後も同じ幅です。本文720pxと左右余白128pxを残せるよう、目次を一時的に縮め、最小幅も残せない時だけ隠します。サイドバーも一時的に縮めます。ウィンドウを広げると保存した幅へ戻ります。縮めた目次の境界線を動かす時は、表示中の幅から変更できます。

本文の末尾には表示領域の高さの半分の余白があり、最後の行を中央付近までスクロールできます。Live Preview・Preview・テキストファイルで共通です。

画像は、本文の右クリックメニューの「画像を挿入…」で選ぶか、画像をコピーしてCmd＋Vで貼り付けるか、Finderから本文へドロップします。どれも記事と同じフォルダの`assets`へ保存し、相対パスの画像の記法を挿入します。複数の画像をまとめてドロップした時は、1回のCmd＋Zで戻せます。文字と一緒にコピーした場合は、文字として貼り付けます。

リストの項目ではTabで1段深く、Shift＋Tabで1段浅くします。表の中ではTabとShift＋Tabで隣のセルへ、Enterで下の行へ移り、そのたびに列の幅をそろえます。最後のセルでTab、最後の行でEnterを押すと行を足します。文字を選んでURLを貼ると、選んだ文字のリンクになります。フェンスのコードブロックは、書いた言語名に応じて色を付けます。対応する言語名は、js、ts、python、rust、json、css、html、sh、yaml、toml、sql、swift、go、java、c、cpp、diffです。

Cmd＋Fの検索パネルでは、大文字と小文字の区別と正規表現を切り替えられます。「置換欄」を開くと、1件ずつの置換とすべての置換ができ、すべての置換は1回のCmd＋Zで戻せます。表示メニューの集中モードは、カーソルのある段落以外を薄く表示します。タイプライター表示は、入力やキー操作のたびにカーソルの行を画面の中央へ寄せます。どちらも選んだ状態は再起動後も有効です。

数式は `$x^2$` / `\(x^2\)`、表示式は `$$...$$` / `\[...\]` を使えます。例えば、次のように書くと分数を表示します。引用・リスト内の表示式や表のセル内の数式にも対応します。

```md
$$
\frac{a}{b}
$$
```

既存Markdownの学術的な数式を読むためMathJaxを使用します。数式を表示する時に読み込み、必要な資産はアプリに同梱してオフラインで使えます。AMS・mathtools・newcommand、記事内の式番号・ラベル・前方参照に対応し、記事間でマクロや番号を引き継ぎません。1式8,192文字、記事全体512式・式本文合計262,144文字まで（JavaScriptの文字列長）。拡張の自動取得はしません。数式専用の入力UIは設けず、原文編集は通常のMarkdown編集として扱います。コード・Front Matter・HTMLブロックは原文のまま。不正な式は原文とエラー表示になり、内容を破棄しません。

| 操作 | キー |
|---|---|
| Live Preview / Preview切替 | Cmd＋Shift＋L |
| ファイルを探す | Cmd＋P |
| 記事内を検索・置換 | Cmd＋F |
| リストの字下げ / 字下げの解除 | Tab / Shift＋Tab |
| 集中モード | Cmd＋Shift＋J |
| タイプライター表示 | Cmd＋Shift＋T |
| 保存 | Cmd＋S |
| 太字の付け外し・入力の開始と終了 | Cmd＋B |
| 斜体の付け外し・入力の開始と終了 | Cmd＋I |
| 選択した文字にリンクを付ける | Cmd＋K |
| Undo / Redo | Cmd＋Z / Shift＋Cmd＋Z |

日本語の変換中は既存のプレビューを維持し、編集位置の追従だけを行います。確定・キャンセル後に最新の本文と選択からプレビューを更新します。

編集後500msで自動保存します。変換中のIME確定を待ち、切り替え・終了の前にも保存を完了します。保存失敗・競合・外部削除では本文を保持し、自動保存を停止します。状態表示の「対応する」から再試行、最新ディスク内容の採用、明示上書き、プロジェクト内への別名保存、破棄確認後の閉じる操作を選べます。

`.md`・`.markdown`のみ編集可能です。UTF-8・BOM・LF/CRLFを保持し、不正UTF-8・混在改行・2MiB超の文書は編集しません。画像はPNG/JPEG/GIF/WebP、20MiB以下・1,600万画素以下。外部URL画像・SVG・HTMLの実行・プロジェクト外やシンボリックリンク経由の参照は許可しません。`.git`・`node_modules`はツリー・検索から除外します。

## ローカル試用用DMG

```sh
npm run tauri build -- --bundles app,dmg --ci
```

生成先は`src-tauri/target/release/bundle/dmg/Nagori_0.1.0_aarch64.dmg`です。DMG内にNagori.appとApplicationsへのリンクを入れています。2026-10-02の生成物は8.50MiB。チェックサム、読み取り専用マウント、製品識別子、署名、同梱CLIを確認しました。Finderでのインストール操作は未検証です。

今回のDMGはad-hoc署名のローカル試用版です。Developer ID Application証明書がなく、公証情報も未設定のため、外部配布用の署名・公証は完了していません。mainへの反映、リリースタグ、GitHub Releaseの公開は行いません。外部配布前に署名・公証を設定し、Macの未確認操作と性能の判断を終えてください。

## 外部配布用の署名と公証

外部配布用のDeveloper ID署名と公証は、環境変数で証明書と資格情報を渡した時だけ実行します。資格情報や証明書はリポジトリに書きません。

```sh
npm run release:sign:check   # 環境変数と証明書の確認だけ。ビルドしない
npm run release:sign         # 署名・公証つきでアプリとDMGを生成し、検証する
```

必要な環境変数は次のとおりです。APPLE_SIGNING_IDENTITYにはキーチェーンにあるDeveloper ID Applicationの証明書名を入れます。公証の資格情報は、APPLE_ID・APPLE_PASSWORD（App用パスワード）・APPLE_TEAM_IDの組か、APPLE_API_ISSUER・APPLE_API_KEY・APPLE_API_KEY_PATHの組のどちらかを渡します。

どれかが足りない場合や証明書がキーチェーンにない場合、スクリプトは何も署名・ビルドせず、案内を出して終了コード2で終わります。ビルド後の検証は、codesignのstrict検証、spctlの評価、staplerの検証の順です。通常のビルド（ad-hoc署名）は、これらの環境変数を設定しない限り従来と同じです。この環境には証明書がないため、署名と公証は実行していません。
